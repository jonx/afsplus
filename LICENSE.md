# Proposed Licensing

This repository is a design draft and the final project owner should confirm licensing before public release.

Recommended split:

- specification/documentation: CC BY 4.0 or another open specification-friendly license that preserves attribution
- portable reference code, headers, tools, and examples: MIT
- code contributed directly to AROS: the license required by the destination AROS component

The on-disk specification should be implementable without requiring permission from the original implementation authors.

Do not copy GPL-only implementation code into code intended for incompatible licensing.
